# VUPRS 客户端使用说明

本文面向客户端使用者, 说明连接, 控制, 显示, 录制, 回放和设置操作. 编译方法, 环境依赖和构建脚本见仓库根目录 [README.md](../README.md). `.vbf` 文件格式见 [vbf_format.md](vbf_format.md). 网络协议见 [protocol_cmd.md](protocol_cmd.md).

## 1. 启动程序

构建完成后运行:

```bash
./build/vuprs_client.exe
```

直接在资源管理器中双击 `vuprs_client.exe` 时, 系统必须能找到 Qt DLL. 可以执行 `windeployqt` 部署依赖, 或把 `D:/QT6.11/6.11.0/mingw_64/bin` 加入系统 `PATH`. 具体步骤见 [README.md](../README.md).

### 1.1 命令行参数

| 参数 | 说明 |
| :--- | :--- |
| `--host <host>` | 配合 `--connect` 使用, 指定服务器地址 |
| `--port <port>` | 配合 `--connect` 使用, 指定服务器端口 |
| `--connect` | 启动后自动连接. 未给 `--host` 时使用 `127.0.0.1`, 未给 `--port` 或端口无效时使用 `18080` |
| `--playback <file>` | 启动后打开指定 `.vbf` 或 `.part` 文件并进入回放 |
| `--tab <index>` | 启动后切换到指定标签页: `0` 为 BF 波形, `1` 为半球能量, `2` 为协议日志 |
| `--screenshot <file>` | 等待一段时间后把主窗口保存为图片并退出, 用于界面自动化 |
| `--screenshot-delay <ms>` | 截图前等待的毫秒数, 默认 `1500`, 最小 `100` |
| `-h`, `--help` | 显示帮助 |
| `--version` | 显示版本 |

示例:

```bash
# DHCP 直连板卡
./build/vuprs_client.exe --connect --host 192.168.50.10 --port 8080

# 连接本机 mock
./build/vuprs_client.exe --connect --host 127.0.0.1 --port 18080

# 打开录制文件回放
./build/vuprs_client.exe --playback recordings/task1234_id1.vbf

# 截取半球能量页
./build/vuprs_client.exe --tab 1 --screenshot hemi.png --screenshot-delay 2000
```

注意: 命令行 `--connect` 不带 `--host` 时使用 mock 地址 `127.0.0.1:18080`. 界面默认连接板卡 `192.168.50.10:8080`.

## 2. 界面布局

左侧是操作区, 从上到下依次为:

- `连接`: 服务器地址, 端口, 连接/断开, 本地 Mock, 直连板卡, 连接状态.
- `算法参数`: 采样率, 声速, 通带, 快照窗口, 协方差平均, 读取/检查/应用按钮和约束提示.
- `波束控制`: 波束算法, 启动/停止/复位, 指向角.
- `空间扫描`: 扫描点数, 最低俯仰角, 开启/关闭扫描.
- `录制`: 录制目录, 开始/停止录制, 回放入口.
- `状态`: 运行, 推理, 故障 ID, 接收速率, 队列和丢帧.

右侧是标签页:

- `BF 波形`: 实时 BF 波形或 `.vbf` 回放.
- `半球能量`: 空间扫描热力图和推理结果柱状图.
- `协议日志`: 控制命令, 响应, 连接和错误日志.

窗口底部状态栏显示最近一次操作结果或错误信息.

## 3. 连接服务器

默认连接方式是 DHCP 直连:

- 板卡 `eth0` 固定为 `192.168.50.10/24`, 并运行 dnsmasq DHCP 服务.
- Windows 以太网适配器保持 `自动获得 IP 地址`; 插线后应获得 `192.168.50.100-200`.
- 板卡不向 PC 下发默认网关和 DNS, 不影响 Wi-Fi.
- 客户端默认连接 `192.168.50.10:8080`.

操作:

1. 确认 Windows 以太网适配器为自动 DHCP. 可以用 `ipconfig /all` 检查 DHCP 服务器是否为 `192.168.50.10`.
2. 启动客户端. `服务器地址` 和 `端口` 默认来自 `client_config.json`, 新安装为 `192.168.50.10:8080`.
3. 点击 `连接`, 或点击 `直连板卡` 自动填入默认板卡地址并连接.
4. 连接成功后按钮变为 `断开`, 地址和端口输入框锁定. 客户端自动发送:
   - `ack`: 读取协议版本, 服务器版本和能力.
   - `read_algorithm_parameters`: 读取当前算法参数并填入界面.
   - `get_status`: 读取运行, 推理, 扫描状态和当前波束算法.
5. 再次点击 `断开` 可主动断开. 断开时如果正在录制, 客户端会停止录制并保留已写入的数据.

如果板卡 IP 或用 `setup_all.sh --ip` 修改过地址, 请同时修改客户端地址和端口. 端口以板卡 `configs/server_config.json` 为准, 默认 `8080`.

`本地 Mock` 按钮会把地址填为 `127.0.0.1`, 端口填为 `18080`, 然后立即连接. 适合无板卡联调.

服务端同一时间只维护一个客户端连接. 新连接会替换旧连接.

## 4. 算法参数

| 界面字段 | 单位 | 默认值 | 范围 | 说明 |
| :--- | :--- | ---: | ---: | :--- |
| `采样率 fs` | Hz | 10000 | 服务端限制, 默认 10 到 120000 | 波束形成器采样率 |
| `声速` | m/s | 346 | 1 到 服务端上限, 默认 100000 | 用于波束形成和空间扫描 |
| `通带下限` | Hz | 500 | 服务端限制, 默认 10 到 60000 | 带通滤波下限 |
| `通带上限` | Hz | 3000 | 服务端限制, 默认 10 到 60000 | 带通滤波上限 |
| `快照窗口` | 等效快照数 | 200 | 1 到 1000000 | 协方差估计窗口 |
| `协方差平均` | 无 | 0.8 | 0 到 0.999 | 协方差矩阵平均系数 |

连接成功后, 客户端从 `ack` 的 `limits` 读取服务端能力, 自动调整 `fs`, 频率和声速范围. `ack` 未提供限制时使用内置默认值.

操作:

- `读取`: 发送 `read_algorithm_parameters`, 用服务端返回值刷新界面. 服务端值超出界面当前范围时, 客户端会扩展显示范围并记录日志, 不会静默钳位.
- `检查`: 发送 `validate_config`, 只让服务端检查参数, 不重启波束形成器.
- `应用`: 发送 `change_algorithm_parameters`, 服务端会重启波束形成器.

`检查` 返回频率分辨率, 通带内 FFT 频点数, 推理帧长和警告. 例如 100 kHz, 512 点 FFT 时:

```text
df = 195.3125 Hz
通带 500..3000 Hz 约 13 个频点
```

客户端在发送前做基本校验:

- `fs` 在服务端限制内.
- `服务端最小频率 <= 通带下限 < 通带上限 < fs/2`.
- 声速大于 0, 快照窗口至少为 1.
- 协方差平均必须在 `[0, 1)` 内.

校验失败或服务端拒绝时, 客户端会记录错误; 参数应用失败后会自动重新读取服务端参数, 避免界面和服务端状态长期不一致.

### 4.1 参数约束和派生指标

算法参数下方显示当前参数对应的派生值:

- `df`: 频率分辨率, 等于 `fs / fft_points`.
- `通带约 N 个频点`: 通带覆盖的 FFT 频点数. 少于 16 个显示 "偏少", 少于 8 个显示 "过少" 并标红.
- `快照约 N s`: 快照窗口按当前 fs 和 FFT 点数折算的近似时间.
- `数据块 N ms`: 每个 BF 数据块的时长, 等于 `dma_buffer_points / fs`.
- `接收队列约 N s`, `录制队列约 N s`: 队列按当前块时长能缓冲的时间.
- `服务端: fs ..., FFT ..., FIR ..., DMA ...`: 服务端能力摘要.

当 DMA 缓冲小于一个推理帧时, 该区域会提示推理不会启动. 这些提示只用于判断参数是否合理, 不会阻止应用; 最终由服务端校验决定.

修改 `fs` 并应用后, 客户端会按新采样率重建波形缓存并复位波形视图. 所有数值参数按服务端协议要求以十进制字符串发送, 保留 6 位小数.

## 5. 波束控制

### 5.1 波束算法

`波束算法` 下拉框提供:

- `dcrcb`
- `mvdr`
- `cbf`

点击 `应用算法` 发送 `change_beamformer`. 切换算法会重启波束形成器.

### 5.2 启动, 停止, 复位

- `启动`: 发送 `start`, 启动波束形成器.
- `停止`: 发送 `stop`.
- `复位`: 发送 `reset`, 停止后按当前配置重新启动.

命令执行后客户端会再次发送 `get_status`, 刷新运行状态和按钮可用性.

### 5.3 指向

- `指向 alt`: 俯仰角, 范围 `-90` 到 `90` 度, `90` 表示天顶.
- `指向 az`: 方位角, 范围 `-180` 到 `180` 度.

修改这两个数值会立即更新半球热力图上的波束指向标记, 但不会下发. 点击 `应用指向` 后才发送 `redirect`.

## 6. 空间扫描

参数:

| 字段 | 默认值 | 范围 | 说明 |
| :--- | ---: | ---: | :--- |
| `points (half)` | 100 | 1 到 10000 | 斐波那契半球网格的半数量, 决定扫描点总数 |
| `alt_min` | 15 | 大于 10 到 90 | 扫描半球的最低俯仰角, 必须大于 10 度; 低于该角度的网格点不生成 |

操作:

- `开启扫描`: 发送 `enable_scan`, 参数为 `points` 和 `alt_min`.
- `关闭扫描`: 发送 `disable_scan`.
- 开启后服务端持续推送扫描帧, 客户端在 `半球能量` 标签页绘制热力图.

热力图说明:

- 圆心附近为天顶, 外圈为低俯仰角. 上方为北 `N`, 右侧为东 `E`, 下方为南 `S`, 左侧为西 `W`.
- 颜色由服务端给出的最小/最大功率归一化到 `uint16`, 客户端按 `min_power_mdb` 和 `max_power_mdb` 还原 dB 值.
- 鼠标悬停显示最近的 `alt`, `az` 和 dB 值.
- 图中标记最大能量点和当前波束指向.
- 双击热力图会把该位置的 `alt` 和 `az` 填入左侧波束控制, 再点击 `应用指向` 才会下发.
- 扫描数据不写入 `.vbf` 录制文件.

### 6.1 推理结果柱状图

`半球能量` 页下方显示推理结果柱状图, 数据来自独立的 `INFERENCE_DATA` 帧:

- 每个 tensor 元素一根柱子, 横轴为元素下标 `#0`, `#1`, ...
- 每帧按当前 tensor 做 min-max 归一化, 显示为 `0` 到 `100%`.
- 最大值对应的柱子用橙色标记, 标题显示 `argmax=#N`.
- 鼠标悬停显示该元素的原始 Q31 值, 解码值和百分比.
- 推理数据与空间扫描独立. 即使未开启扫描, 只要波束形成器运行且推理可用, 仍会收到推理帧.
- 推理帧频率不超过 10 Hz.
- `故障ID` 状态更新为最近一帧推理 tensor 的 argmax 下标.

## 7. BF 波形

### 7.1 实时波形控制

- `自动跟随`: 视图跟随最新数据滚动. 默认开启.
- `冻结`: 冻结当前视图, 后台仍继续接收和缓存数据.
- `窗口`: 显示时间窗长度, 范围 `0.5` 到 `120` 秒.
- `重置视图`: 恢复自动跟随和默认窗口; 回放时恢复完整录制视图.

### 7.2 鼠标操作

实时模式:

| 操作 | 效果 |
| :--- | :--- |
| 滚轮 | 以鼠标位置为锚点缩放时间轴 |
| `Ctrl + 滚轮` | 缩放纵轴 |
| 左键拖动 | 平移视图 |
| 右键或中键拖动 | 平移视图 |
| 双击波形 | 恢复自动跟随和默认视图 |
| 鼠标悬停 | 显示时间, 样本下标和幅度 |

回放模式的鼠标操作不同, 见第 9 节.

波形左上角显示当前采样率, 显示窗口长度和缓存样本数. 纵轴在自动模式下按当前可见数据范围缩放; 使用 `Ctrl + 滚轮` 后切换为手动范围.

左侧状态分组中的 `接收` 显示每秒帧数, 当前队列深度, 丢帧计数和累计接收字节数.

## 8. 录制

录制前必须先连接服务器. 未连接时点击 `开始录制` 只会记录提示, 不会创建文件.

### 8.1 录制目录

- 在 `录制目录` 中直接输入路径, 或点击 `选择目录...`.
- 选择后立即写入配置, 本次会话生效.
- 相对路径按当前用户的 `文档` 目录解析.
- 配置模板中的默认值为 `recordings`, 通常解析为 `文档/recordings`. 如果配置中没有录制目录, 客户端回退到 `文档/VUPRS/recordings`.

### 8.2 文件命名

- 客户端每次启动生成一个任务 ID: Unix 秒时间戳的后 4 位十进制数字, 不足 4 位时左侧补零, 例如 `task0427`.
- 文件名格式为 `task<任务ID>_id<序号>.vbf`, 序号从 1 开始.
- 开始录制前会扫描目录中同一任务 ID 的已有文件, 包括 `.part` 文件, 取最大序号加 1. 因此重启客户端或任务 ID 重复时不会覆盖已有文件.
- 如果目标 `.vbf` 已存在, 录制启动失败并提示.

### 8.3 开始和停止

1. 确认 `录制目录` 正确.
2. 点击 `开始录制`. 按钮变为 `停止录制`, 目录输入和选择按钮禁用.
3. 录制期间左侧显示任务 ID, 已写帧数, 数据量和丢弃帧数.
4. 点击 `停止录制` 后, 客户端写入文件尾, 关闭文件, 把 `.vbf.part` 重命名为 `.vbf`, 并弹窗显示完整保存路径.

录制在独立线程中进行. 网络接收队列到录制线程之间还有一个队列; 队列满时会丢弃最旧的帧并计数, 录制状态显示丢弃数量. 丢弃会造成录制文件中 `sequence` 不连续, 但已写入的记录仍然有效.

断开连接时会自动停止录制. 程序正常退出时也会尝试停止录制并写入文件尾.

### 8.4 异常退出

如果程序崩溃或被强制结束, 目录中会保留未完成的 `.vbf.part` 文件. 该文件没有文件尾, 但其中完整的记录仍可回放或导出 CSV. 客户端在回放时会记录 "文件末尾不完整" 或 "缺少文件尾" 提示.

只录制 BF 波形. 空间扫描数据和推理 tensor 不会写入 `.vbf`. BF 记录头中旧的推理字段为兼容保留, 新录制的实时帧写 `flags=0`, `inference_identity=-1`; 旧录制文件仍可回放和导出.

## 9. 回放

### 9.1 打开文件

可以通过以下入口打开回放:

- 菜单 `文件 -> 打开回放...`, 快捷键 `Ctrl+O`.
- 左侧 `录制` 分组中的 `回放...`.
- 命令行 `--playback <file>`.

文件选择框支持 `.vbf` 和 `.part`. 载入时:

- 客户端把整个文件读入内存, 文件大于 512 MiB 时会先弹窗确认.
- 采样率以第一条 BF 记录为准; 如果该帧采样率为 0, 则使用文件头 JSON 中的 `sample_rate_millihz`.
- 采样率非 0 且与首帧不一致的帧会被跳过, 跳过数量写入协议日志.
- 文件末尾不完整时只载入完整的帧.
- 只有 BF 记录, 没有扫描数据, 因此回放只显示 BF 波形.

载入完成后自动切换到 `BF 波形` 标签页并显示回放控制条. 实时接收和录制不受回放影响.

### 9.2 播放控制

回放控制条包含:

- 文件名标签: 悬停显示完整路径.
- `播放` / `暂停`: 播放或暂停. 播放到末尾自动暂停.
- `时间段...`: 打开时间段选择对话框.
- `退出回放`: 返回实时波形.
- `导出 CSV...`: 导出当前文件.
- 进度滑块: 拖动定位. 时间标签显示当前位置和总时长.

回放期间 `自动跟随` 禁用. 修改 `窗口` 会清除已选择的时间段.

### 9.3 时间段选择

两种方式:

1. 点击 `时间段...`, 输入开始时刻和结束时刻, 单位为秒, 保留 3 位小数. 结束时刻必须大于开始时刻, 且不能超过录制总时长.
2. 在波形绘图区按住鼠标左键拖动框选. 拖动距离小于 3 像素时不会触发选择; 所选范围少于 16 个采样时提示时间段过短.

选择后:

- 正在播放的回放会暂停.
- 视图切换到所选时间段, 整段数据铺满波形窗.
- 播放只在该时间段内进行, 到达结束位置后暂停.
- 可以在已放大的视图上继续框选, 进一步放大.
- 拖动进度滑块到时间段之外会清除时间段.
- 双击波形或点击 `重置视图` 恢复完整录制视图并清除时间段.

回放时按住鼠标右键拖动可以平移视图. 此时左键用于框选, 不再用于平移. 滚轮缩放仍然可用.

### 9.4 导出 CSV

在回放控制条点击 `导出 CSV...`:

- 默认输出到源 `.vbf` 同目录, 文件名为 `<源文件名>.csv`.
- 输出路径不能与 `.vbf` 源文件相同.
- 导出的是整个 `.vbf` 文件, 不是当前选择的时间段.
- 导出过程显示进度, 可以取消.
- 源文件末尾不完整或缺文件尾时, 只导出完整的帧, 并在日志中提示.

CSV 为 UTF-8, 开头是 4 行注释:

```text
# VUPRS BF CSV
# source=<源文件绝对路径>
# exported_utc=<导出时间, ISO 8601 UTC>
# metadata=<.vbf 文件头 JSON>
```

随后是表头:

```text
frame_index,sequence,timestamp_ns,arrival_ms,sample_rate_hz,sample_index,global_sample,time_s,global_time_s,amplitude,raw_q16_16,inference_identity,inference_valid
```

| 列 | 说明 |
| :--- | :--- |
| `frame_index` | BF 记录序号, 从 0 开始 |
| `sequence` | 服务端帧序列号 |
| `timestamp_ns` | 服务端发送时间戳, Unix 纳秒 |
| `arrival_ms` | 客户端接收时间, Unix 毫秒 |
| `sample_rate_hz` | 该帧采样率, Hz |
| `sample_index` | 帧内采样下标 |
| `global_sample` | 导出文件内的累计采样下标 |
| `time_s` | 帧内时间, 秒 |
| `global_time_s` | 按采样率累计的时间, 秒 |
| `amplitude` | Q16.16 归一化幅度, 等于 `raw_q16_16 / 65536` |
| `raw_q16_16` | 原始 `int32` 值 |
| `inference_identity` | 旧录制文件中的推理结果 ID; 新协议实时录制为 `-1` |
| `inference_valid` | 旧录制文件中的推理有效标志; 新协议实时录制为 `0` |

CSV 每个采样一行, 体积通常远大于原 `.vbf` 文件.

新协议中推理 tensor 独立推送, 不写入 `.vbf`, 因此 CSV 中的推理列只对旧录制文件有意义.

## 11. 状态和日志

`状态` 分组显示:

- `运行`: 波束形成器是否运行.
- `推理`: 推理是否就绪.
- `故障ID`: 最近一帧推理 tensor 的 argmax 下标; 没有推理数据时显示 `无有效推理`.
- `接收`: 每秒帧数, 队列深度, 丢帧数, 累计接收字节数.

`协议日志` 标签页记录:

- 连接, 断开和协议错误.

- 参数校验失败和文件错误.

状态栏临时显示最近一次操作结果. 详细错误请查看协议日志.

## 13. 常见问题

### 程序无法启动, 提示缺少 Qt 库

双击运行时系统需要找到 Qt DLL. 执行:

```bash
D:/QT6.11/6.11.0/mingw_64/bin/windeployqt.exe build/vuprs_client.exe
```

或把 `D:/QT6.11/6.11.0/mingw_64/bin` 加入系统 `PATH`.

### 点击连接后没有反应或连接失败

- 确认板卡 `vuprs-server.service` 或 `run_server.sh` 已启动.
- Windows 以太网适配器必须为自动 DHCP; 用 `ipconfig /all` 检查是否拿到 `192.168.50.100-200`, DHCP 服务器是否为 `192.168.50.10`.
- 用 `Test-NetConnection 192.168.50.10 -Port 8080` 检查 TCP 8080.
- 确认地址和端口正确; 如果板卡 IP 或端口改过, 客户端也要改.
- 确认 Windows 防火墙允许该端口.
- 无板卡时先启动 `vuprs_mock_server`, 再点击 `本地 Mock`.

### 连接成功但没有波形

- 点击 `启动` 启动波束形成器.
- 查看 `状态` 分组中的运行和推理状态.
- 查看协议日志中的错误响应.

### 半球能量页没有数据

- 点击 `开启扫描`.
- 确认服务端支持扫描并已返回扫描帧.
- 查看协议日志是否有 `enable_scan` 失败信息.

### 推理柱状图没有数据

- 确认左侧 `推理` 显示可用; 模型未加载或未就绪时服务端不会推送推理帧.
- 点击 `启动`, 推理依赖波束形成器运行.
- 查看协议日志中的 `inference_tensor_length` 和长度不一致提示.
- 推理柱状图与扫描开关无关, 未开启扫描也可能收到推理数据.

### 无法开始录制

- 必须先连接服务器.
- 检查录制目录是否存在写权限.
- 检查磁盘空间.
- 如果目标文件已存在, 更换目录或删除同名文件.

### 回放打不开

- 文件必须是本客户端的 `.vbf` 或未完成的 `.vbf.part`.
- 文件头损坏, 版本不支持, 元数据无效或没有 BF 数据时会提示错误.
- 超大文件需要较多内存, 载入前会弹窗确认.

### CSV 文件过大

CSV 每个采样一行. 长录制会生成很大的 CSV. 如需节省空间, 保留 `.vbf` 原文件, 只对需要的片段另行处理.

## 附录: 数据单位

- BF 采样为 `int32` Q16.16: `amplitude = raw / 65536`.
- 推理 tensor 为 `int32` Q31: `value = raw / 2^31`; 柱状图按每帧 tensor 做 min-max 归一化到 `0..100%`.
- 采样率字段 `sample_rate_millihz` 的单位为 `Hz * 1000`.
- 扫描功率字段 `min_power_mdb` 和 `max_power_mdb` 的单位为 `dB * 1000`.
- 扫描俯仰角字段 `alt_min_mdeg` 的单位为 `deg * 1000`.
- 扫描归一化值还原 dB:

  ```text
  power_dB = min_power_mdb / 1000 + (raw / 65535.0) * (max_power_mdb - min_power_mdb) / 1000
  ```

- 时间戳: `timestamp_ns` 为 Unix 纳秒, `arrival_ms` 为 Unix 毫秒.
